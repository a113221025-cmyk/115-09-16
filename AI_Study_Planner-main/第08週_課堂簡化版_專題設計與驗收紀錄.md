## 四、環境、交付與反思

遇到的問題：

在製作 AI 智慧讀書計畫助手的過程中，遇到 GitHub 檔案上傳、Codespaces 資料夾路徑、Python 套件安裝，以及 OpenAI API Key 設定等問題。程式一開始無法正常產生讀書計畫，也曾出現 AuthenticationError 與 StreamlitSecretNotFoundError。

修改程式或提示：

先確認 GitHub 上的檔案位置，使用終端機安裝 requirements.txt 所列套件，再設定 OpenAI API Key。經過測試與調整後，已能在原本的開發環境成功產生讀書計畫。

修改後的結果：

目前已成功顯示 7 天英文單字讀書計畫，包含每天的學習主題與學習任務。程式也已上傳至教授指定的 GitHub Repository，但新的 Codespaces 仍需完成 API 設定與雲端部署驗收。

學習心得：

透過這次專題，我學會使用 Python、Streamlit 和 OpenAI API 製作簡單的 AI 應用程式，也學會如何使用 GitHub 儲存程式碼、透過 Codespaces 執行程式，以及處理執行過程中的錯誤。我發現製作 AI 工具不只是寫程式，還需要考慮使用者操作方式、輸入資料檢查、API 安全性與測試結果。這次經驗讓我更了解 AI 應用程式從設計到實際運作的流程。
